
# Adaptive Workforce Control Tower

Minimal MVP skeleton for an AI-driven norm‐kadro and shift‑planning platform.

## Structure
```
backend/        # FastAPI micro‑services
frontend/       # React dashboard (placeholder)
ml/             # Notebooks / model scripts
docker-compose.yml
```

## Quick Start
```bash
git clone <your-fork> workforce-planning
cd workforce-planning
docker compose up --build
```
Visit http://localhost:8000/docs for interactive API.
